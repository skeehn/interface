skeehn is the ASCII-native UI framework where texture is a first-class design primitive. It uses dither patterns and monospace typography to create a distinctive terminal aesthetic.

Install via npm with npx skeehn init, then import the CSS and optional JS modules into your project.

Most components are CSS-only. Minimal JS is provided for interactive behaviors like tabs, accordions, and dropdowns.

Override --sk-* custom properties to customize colors, spacing, typography, and dither patterns globally or per component.

skeehn supports all modern browsers including Chrome, Firefox, Safari, and Edge.
