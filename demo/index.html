What makes skeehn different from shadcn?

shadcn provides copy-paste React components. skeehn provides a zero-dependency ASCII dither rendering system — texture as a first-class design primitive alongside color and spacing. Fundamentally different layers of abstraction.

shadcn gives you React components. skeehn gives you a rendering primitive — ASCII dither texture — as a first-class design element. Every component uses ░▒▓█ patterns as texture, not decoration. It runs on zero JS dependencies, ships pure CSS+HTML, and has native MCP support so AI agents can install and compose it directly.
